# Design: Sprint 8 — ML Training + Synthetic Data Pipeline

## Technical Approach

Create a `SyntheticCrackGenerator` (OpenCV Bézier curves on noise/pattern backgrounds, YOLO .txt output) → populate `ml/dataset/` → run existing `train_yolov8.py` (unchanged) → autogenerated `best.onnx` → wire `OnnxDetector` via config flag → integration test that proves `CrackResult` flow. Every component already exists except the generator; the training script, detector class, factory, and pipeline loop are fully implemented. This sprint populates the data vacuum that has kept the ML path in permanent fallback.

---

## Architecture Decisions

### Decision: Inline train/val split vs. calling `prepare_dataset.py split`

| Option | Tradeoff | Decision |
|--------|----------|----------|
| **Generator does inline split** | Single CLI call; no subprocess; self-contained | ✅ |
| Call `prepare_dataset.py split` | Reuses existing tool; subprocess coupling | ❌ |

**Rationale**: The generator writes to a temp staging dir then moves files into `train/` and `val/`. This is ~30 lines of `shutil.move` logic — trivial compared to the subprocess complexity and path coupling of a second script. `prepare_dataset.py split` remains available for manual use.

### Decision: Synthetic crack rendering strategy

| Option | Tradeoff | Decision |
|--------|----------|----------|
| **Bézier polylines + dilation layers** | OpenCV-native; no extra dep; width control via iteration count | ✅ |
| Perlin noise / procedural texture | Heavy compute; less controllable per-image | ❌ |

**Rationale**: `cv2.polylines` on 4-6 control points with random offsets gives natural-looking curves. Applying `cv2.dilate` iteratively increases stroke width in 1px steps — trivially maps to the three target classes at 640px reference (fina ≤2px, media 3–5px, gruesa 6–12px).

### Decision: No new config fields

| Option | Tradeoff | Decision |
|--------|----------|----------|
| **Use existing config.detector_method / model_path** | Zero config changes; `DETECTOR_METHOD=onnx MODEL_PATH=...` activates ML path | ✅ |
| Add sprint-8-specific fields | More env vars; needs config.py change | ❌ |

**Rationale**: `EdgeConfig` already has `detector_method`, `model_path`, `confidence_threshold`. The sprint-7 `data_collection` block already captures raw frames to `data/training/raw/`. The training script is CLI-driven with its own args (`--epochs`, `--batch`, `--imgsz`). No config.py changes needed.

### Decision: onnxruntime commented out in `edge/requirements.txt` — keep it that way

| Option | Tradeoff | Decision |
|--------|----------|----------|
| **Leave onnxruntime commented in edge/requirements.txt** | Edge RPi keeps light deps; training laptop uses ml/requirements.txt | ✅ |
| Uncomment onnxruntime | Forces install on RPi even when not using ONNX | ❌ |

**Rationale**: `ml/requirements.txt` already lists `ultralytics`, `onnx`, `onnxruntime`. The edge device only needs `onnxruntime` (specifically `onnxruntime-silicon` for dev laptop). Documented install command is `pip install onnxruntime` or `pip install onnxruntime-silicon`.

## Interfaces / Contracts

### SyntheticCrackGenerator

```python
@dataclass
class CrackSpec:
    """Describes one synthetic crack to render."""
    control_points: list[tuple[int, int]]   # Bézier control points (image coords)
    target_width_px: int                     # after dilation iterations
    class_id: int                            # 0=fina, 1=media, 2=gruesa

class SyntheticCrackGenerator:
    def __init__(
        self,
        output_dir: str = "ml/dataset",
        num_images: int = 1000,
        imgsz: int = 640,
        crack_count: tuple[int, int] = (1, 5),   # (min, max) per image
        noise_level: float = 0.1,                 # background noise stddev
        background: str = "gradient",             # solid | gradient | texture
        val_ratio: float = 0.2,
        seed: int | None = None,
    ) -> None: ...

    def generate(self) -> None:
        """Generate all images, split into train/val, write data.yaml."""

    def _make_background(self, rng: np.random.Generator) -> np.ndarray:
        """Return a BGR background image (solid/gradient/texture)."""

    def _generate_crack(
        self, imgsz: int, rng: np.random.Generator
    ) -> CrackSpec | None:
        """Random control points, width → class_id."""

    def _render_crack(self, canvas: np.ndarray, spec: CrackSpec) -> np.ndarray:
        """Draw polylines + dilate. Returns crack_mask (binary)."""

    def _compute_yolo_bbox(
        self, mask: np.ndarray, imgsz: int
    ) -> tuple[float, float, float, float]:
        """From mask contour extremes → (x_center, y_center, w, h) normalized."""

    def _write_label(
        self, label_path: Path, class_id: int, bbox: tuple[float, float, float, float]
    ) -> None: ...

    def _split_train_val(self, staging: Path) -> None:
        """Move files from staging into train/ and val/."""

    def _write_data_yaml(self) -> None:
        """Create data.yaml compatible with train_yolov8.py format."""
```

### CLI interface

```
generate_synthetic.py
  --output         ml/dataset/       Output directory
  --num-images     1000              Total images to generate
  --imgsz          640               Image size (square)
  --crack-count    1                 Cracks per image (0 = background only, or min-max)
  --noise-level    0.1               Background noise stddev (0.0–1.0)
  --background     gradient          Background style: solid | gradient | texture
  --val-ratio      0.2               Validation split proportion
  --seed           None              RNG seed for reproducibility
```

### Class-to-width mapping (at 640px reference)

| Class ID | Name | Pixel width | Classification equivalent |
|----------|------|-------------|--------------------------|
| 0 | `fisura_fina` | 1–2px | < 0.3 mm |
| 1 | `fisura_media` | 3–5px | 0.3–1.0 mm |
| 2 | `fisura_gruesa` | 6–12px | > 1.0 mm |

### YOLO label format

```
<class_id> <x_center_norm> <y_center_norm> <width_norm> <height_norm>
```
All values in [0, 1] relative to image dimensions. Empty label = no `.txt` file (negative sample). Validated by `prepare_dataset.py validate`.

### `OnnxDetector` (existing — no changes)

```python
class OnnxDetector(BaseDetector):
    def __init__(self, model_path: str) -> None: ...
    def process(self, frame: np.ndarray) -> list[CrackResult]: ...
```

On valid ONNX: runs inference via `onnxruntime.InferenceSession`, returns scaled `CrackResult` list with confidence > threshold. On failure (`ImportError`, `FileNotFoundError`, `RuntimeError`): `_session = None`, `process()` delegates to `self._fallback` (OpenCV). `create_detector("onnx")` always returns `OnnxDetector` — fallback is internal.

## Integration Points

### 1. Generator → Dataset

```
$ python edge/ml/generate_synthetic.py --output ml/dataset --num-images 1000 --imgsz 640
```

Output: `ml/dataset/train/{images,labels}/` + `ml/dataset/val/{images,labels}/` + `ml/dataset/data.yaml`

### 2. Dataset → Training

```
$ python edge/ml/train_yolov8.py --data ml/dataset/data.yaml --epochs 50 --batch 4 --imgsz 416
```

Training script is untouched. Auto-creates `data.yaml` if missing. Auto-exports to `best.onnx`.

### 3. ONNX model → Edge pipeline

```
$ DETECTOR_METHOD=onnx MODEL_PATH=ml/models/argos-crack-detector/weights/best.onnx python -m edge.main
```

Or via `.env`: `DETECTOR_METHOD=onnx`, `MODEL_PATH=ml/models/argos-crack-detector/weights/best.onnx`

### 4. Test-only injected config (no env needed)

Tests set `config.detector_method` and `config.model_path` directly, or use `unittest.mock.patch.object`.

## Testing Strategy

| Layer | What to Test | Approach |
|-------|-------------|----------|
| **Unit** | `SyntheticCrackGenerator._generate_crack()` | Fixed seed → deterministic control points, class_id in range, valid width |
| **Unit** | `SyntheticCrackGenerator._compute_yolo_bbox()` | Known mask → verify normalized bbox values match spec scenario |
| **Unit** | `SyntheticCrackGenerator._write_label()` | Temp dir → verify .txt format: `class_id x y w h` normalized [0,1] |
| **Unit** | `SyntheticCrackGenerator._make_background()` | Each background mode produces correct size, dtype, color range |
| **Unit** | `SyntheticCrackGenerator.generate()` with `num_images=10` | 10 .jpg + 10 .txt created; negative samples (10%) have no .txt |
| **Unit** | OnnxDetector mock session | Inject mock `onnxruntime.InferenceSession` → verify `CrackResult` items have correct x, y, width, height, confidence, classification |
| **Unit** | OnnxDetector fallback | `model_path=/nonexistent` → `_session` is None → `process()` returns OpenCV results (not empty) |
| **Unit** | OnnxDetector calibration | Calibration `pixels_per_mm` → `width_mm` uses calibrated ratio (no warning log) |
| **Integration** | Full pipeline with synthetic frame | Generate synthetic crack image → feed to `main.py` with `DETECTOR_METHOD=onnx` → verify `CrackResult` → tracking → velocity → alert → **zero OpenCV fallbacks** |
| **Integration** | No-crack image skips tracking | Background-only frame → empty detection list → no tracking/velocity/alert |

### Test file additions:
- `edge/edge/tests/test_onnx_detector.py` — OnnxDetector unit tests (mock ONNX session, fallback, calibration)
- `edge/edge/tests/test_synthetic_pipeline.py` — Full pipeline E2E (synthetic frame → ONNX → result → no fallback)
- Generator tests are **inline** in `generate_synthetic.py` as a `if __name__ == "__main__"` smoke test, or in a separate `tests/test_generate_synthetic.py` following existing pattern

### Mock strategy for OnnxDetector

```python
# test_onnx_detector.py
@patch("onnxruntime.InferenceSession")
def test_onnx_returns_crack_result(self, mock_session):
    mock_session.return_value.run.return_value = [
        np.array([[[0, 0, 100, 200, 0.85, 0]]])  # [x1, y1, x2, y2, conf, class]
    ]
    detector = OnnxDetector("fake.onnx")
    frame = np.zeros((480, 640, 3), dtype=np.uint8)
    results = detector.process(frame)
    assert len(results) == 1
    assert results[0].confidence == 0.85
    assert results[0].classification == CrackClassification.FINA
```

## Migration / Rollout

No data migration required. Feature flags:
- `DETECTOR_METHOD=onnx` (existing) — activates ML detection path
- `MODEL_PATH=.../best.onnx` (existing) — points to trained model
- Default `DETECTOR_METHOD=opencv` — zero risk; pipeline stays in OpenCV fallback until explicitly switched

### Rollback
1. Delete `generate_synthetic.py`
2. Delete `ml/dataset/` (if generated data only)
3. Delete `ml/models/argos-crack-detector/`
4. Delete test files `test_onnx_detector.py`, `test_synthetic_pipeline.py`
5. Uninstall `ultralytics`, `onnx`, `onnxruntime` (use `pip uninstall`)
6. Reset `.env`: `DETECTOR_METHOD=opencv`, `MODEL_PATH=` (empty)
